# Випереджувальне буферизування ін'єкції та мікрофейд у драйвері для захисту від опустіння буфера

У режимі «Ін'єкція в мікрофон» системний аудіограф Windows (`audiodg.exe`) опитує цільовий мікрофон блоками по 10 мс (480 фреймів при 48 кГц) від апаратного тактового генератора мікрофона (наприклад, USB-кварцу Fifine). Водночас навушники моніторингу користувача працюють від власного DAC (наприклад, Realtek при 44,1 кГц). Щоб усунути апаратний дрейф таймінгів між звуковими картами та запобігти виникненню розривів звуку (опустіння буфера), що спричиняли високочастотне шипіння/білий шум:

1. **Випереджувальне буферизування (Lead Buffer)**:
   При старті або відновленні треку програма підтримує в буфері ін'єкції (`InjectionShm`) випереджувальний запас у 100–120 мс (при загальній ємності кільцевого буфера 1000 мс).
2. **Розв'язка читачів (Multi-reader Ring Buffer)**:
   Внутрішній кільцевий буфер декодера підтримує незалежні покажчики читання для ін'єкції та моніторингу. Ін'єкція наповнює буфер драйвера наперед, не очікуючи блокуючого виводу в навушники, а при скиданні (Stop/Seek) обидва покажчики та буфер драйвера скидаються миттєво через `flush_seq`.
3. **Захисний мікрофейд (Micro-fade Out) у драйвері**:
   У нативному C++ коді `mpad_dsp_process_shm_block` у разі аварійного опустіння буфера (`to_mix < total_samples`) залишок наявного сигналу плавно згасає за 16–32 семпли замість прямокутного обриву до нуля, що повністю усуває спектральні сплески та клацання.

## Considered Options

- **Жорстка синхронізація через блокуючий sleep / таймер Windows**: відкинуто через нестабільність `time.sleep` при таймінгах менше 10 мс та неминучий дрейф частот між різними звуковими картами.
- **Збільшення blocksize до 480 без випереджувального буфера**: відкинуто, оскільки при найменшому навантаженні на CPU буфер одразу падав до 0.

## Consequences

- Повне усунення шипіння та 6500+ випадків опустіння буфера.
- Відсутність відчутної затримки для користувача завдяки миттєвому скиданню через `flush_seq`.
- Чисте стереозвучання в навушниках паралельно з адаптованим моно/стерео потоком у мікрофоні.
