# Переробка смуги керування треком, інтеграція обкладинки та функція «Мут для інших»

У MusicPad повністю перероблено верхню смугу керування треком (`top_bar`): збільшено висоту до 56 px, вбудовано інформацію про поточний трек (`Назва • Виконавець`) та його обкладинку (40×40 px), вимкнено спливаючу хмарку «Зараз грає», додано кнопку «Мут для інших» та переміщено кнопку циклічного відтворення (Loop).

## Context & Motivation

1. **Неінформативна та затісна смуга керування**:
   - Раніше верхня панель керування мала висоту лише 28 px і містила виключно кнопки відтворення, повзунок перемотування та регулятор гучності.
   - Інформація про те, який трек зараз грає, виводилася виключно у спливаючій хмарці сповіщень (`SpeechBubble`) над кнопкою чату або в діалогових статусах. Хмарка перекривала елементи інтерфейсу та створювала візуальний шум при частих перемиканнях треків.
   - Користувач не мав змоги постійно бачити назву поточної пісні, виконавця та обкладинку під час прослуховування.

2. **Потреба у приватному прослуховуванні (мут для інших)**:
   - У сценаріях ігор та голосових конференцій (Discord, Teams тощо) користувач часто бажає чути музику в навушниках (моніторинг), але не транслювати її співрозмовникам (у віртуальний кабель або ін'єкцію в мікрофон).
   - Раніше кнопка муту приглушувала звук скрізь — і для співрозмовників, і в навушниках користувача. Потрібна була окрема кнопка «Мут треку для інших» без зміни гучності моніторингу.

3. **Розташування кнопки Loop**:
   - Кнопка циклу `🔁 Loop` знаходилася в правій частині нижньої панелі (`bottom_bar`), відірвано від основних контролів відтворення у верхній смузі.

## Decision

1. **Дворядкова архітектура `top_bar` висотою 56 px**:
   - **Лівий блок**: кнопки відтворення (`▶/⏸`, `⏹`, `|◀`, `▶|`) та вертикальний роздільник.
   - **Центральний блок**:
     - *Верхній рядок*: відмітка часу (`0:00`) та плавний повзунок перемотування (`SoundpadTimelineSlider`).
     - *Нижній рядок*:
       - Повністю зліва: назва композиції жирним білим текстом і виконавець приглушеним сірим через роздільник-крапку: `{Назва}  •  {Виконавець}` (при відсутності треку: `Нічого не відтворюється`).
       - Повністю з правого боку: квадратна обкладинка треку 40×40 px (для YouTube-треків — реальна обкладинка, для локальних аудіофайлів або порожнього стану — стильна нота-заглушка).
   - **Правий блок**:
     - *Верхній рядок*: кнопка повного муту треку (з іконкою ноти) та повзунок загальної гучності (`SoundpadVolumeSlider`).
     - *Нижній рядок*: нова кнопка «Мут для інших» (`btn_tb_mic_mute`) та праворуч від неї кнопка `🔁 Loop` (`btn_tb_loop`).
   - Кнопку `Loop` видалено з нижнього бару (`bottom_bar`) для уникнення дублювання.

2. **Логіка «Мут для інших» у `AudioEngine`**:
   - Додано властивість `mute_broadcast: bool`.
   - При активному муті для інших:
     - У режимі «Віртуальний кабель»: семпли треку, що додаються в потік трансляції `stream.write()`, множаться на 0.0 (тиша для співрозмовників), але потік моніторингу `monitor_stream.write()` отримує звук повної гучності.
     - У режимі «Ін'єкція в мікрофон»: запис у буфер спільної пам'яті драйвера (`shm`) зануляється або вимикається, тоді як моніторинг у навушниках продовжує звучати без змін.
   - Іконка кнопки відображає мікрофон `🎙️` (коли розмучено) та мікрофон із червоним хрестиком `🎙️❌` (коли замучено для інших).
   - Стан зберігається в `musicpad_state.json` під ключем `mute_track_to_others`.

3. **Вимкнення спливаючої хмарки «Зараз грає»**:
   - При запуску треку (`_play_local_track`, `_play_album_track`, `_play_stream_track`) спливаюча хмарка `SpeechBubble` більше не показується автоматично. Інформація постійно оновлюється безпосередньо у смузі керування треком.

## Consequences

- Інтерфейс отримує сучасний вигляд повноцінного медіаплеєра з постійним відображенням метаданих та обкладинки.
- Користувач отримує можливість одним кліком ізолювати звук треку від співрозмовників, продовжуючи слухати його у навушниках.
- Усунуто візуальний шум від постійних спливаючих хмарок сповіщень.
