# Переробка смуги керування треком, інтеграція обкладинки та функція «Мут для інших»

У MusicPad повністю перероблено верхню смугу керування треком (`top_bar`): збільшено висоту до 60 px, вбудовано відцентрований блок інформації про поточний трек (`{Назва}  •  {Виконавець}` та квадратну обкладинку 40×40 px), вимкнено спливаючу хмарку «Зараз грає», додано кнопку «Мут для інших», переміщено кнопку циклічного відтворення (Loop) та виправлено позиціонування кнопки налаштувань щодо кнопки очищення кешу.

## Context & Motivation

1. **Неінформативна та затісна смуга керування**:
   - Раніше верхня панель керування мала висоту лише 28 px і містила виключно кнопки відтворення, повзунок перемотування та регулятор гучності.
   - Інформація про те, який трек зараз грає, виводилася виключно у спливаючій хмарці сповіщень (`SpeechBubble`) над кнопкою чату або в діалогових статусах. Хмарка перекривала елементи інтерфейсу та створювала візуальний шум при частих перемиканнях треків.
   - Користувач не мав змоги постійно бачити назву поточної пісні, виконавця та обкладинку під час прослуховування.

2. **Потреба у приватному прослуховуванні (мут для інших)**:
   - У сценаріях ігор та голосових конференцій (Discord, Teams тощо) користувач часто бажає чути музику в навушниках (моніторинг), але не транслювати її співрозмовникам (у віртуальний кабель або ін'єкцію в мікрофон).
   - Раніше кнопка муту приглушувала звук скрізь — і для співрозмовників, і в навушниках користувача. Потрібна була окрема кнопка «Мут треку для інших» без зміни гучності моніторингу.

3. **Розташування кнопки Loop та кнопок інфо-панелі**:
   - Кнопка циклу `🔁 Loop` знаходилася в правій частині нижньої панелі (`bottom_bar`), відірвано від основних контролів відтворення у верхній смузі.
   - Кнопка налаштувань (`🔧`) опинялася ліворуч від кнопки «Очистити кеш», тоді як вона має бути крайньою праворуч на інфо-панелі.

## Decision

1. **Дворядкова архітектура `top_bar` висотою 60 px**:
   - **Лівий блок**: кнопки відтворення (`▶/⏸`, `⏹`, `|◀`, `▶|`) та вертикальний роздільник (`rowspan=2`).
   - **Центральний блок**:
     - *Верхній рядок*: відмітка часу (`0:00`) та плавний повзунок перемотування (`SoundpadTimelineSlider`).
     - *Нижній рядок (відцентрований блок)*:
       - `{Назва}` жирним текстом та `  •  {Виконавець}` приглушеним шрифтом.
       - Праворуч від виконавця (відступ 10 px): квадратна обкладинка треку 40×40 px (для YouTube/альбомів — обкладинка, для локальних аудіофайлів чи зупиненого стану — стильна нота-заглушка).
       - Увесь блок горизонтально та вертикально відцентровано під повзунком перемотування за допомогою контейнера `place(relx=0.5, rely=0.5, anchor="center")`.
   - **Правий блок**:
     - *Верхній рядок*: кнопка повного муту треку (з іконкою ноти) та повзунок загальної гучності (`SoundpadVolumeSlider`).
     - *Нижній рядок*: нова кнопка «Мут для інших» (`btn_tb_mic_mute`) та праворуч від неї кнопка `🔁 Loop` (`btn_tb_loop`).
   - Кнопку `Loop` видалено з нижнього бару (`bottom_bar`) для уникнення дублювання.

2. **Підтримка виконавця у потоці відтворення**:
   - У `StreamTrack` додано поле `artist: str = ""`.
   - Додано збереження `_current_track_artist` у додатку та автоматичний пошук виконавця у локальних треках при викликах зворотного зв'язку `_on_track_title`, що запобігає затиранню імені виконавця під час відтворення.

3. **Порядок кнопок інфо-панелі**:
   - Кнопка налаштувань (`btn_wrench`) запакована першою праворуч, а кнопка «🗑 Очистити кеш» (`btn_clear_cache`) розміщується лівіше від неї (`after=self.btn_wrench`), забезпечуючи постійне перебування гайкового ключа крайнім справа.

4. **Логіка «Мут для інших» у `AudioEngine`**:
   - Додано властивість `mute_broadcast: bool`.
   - При активному муті для інших звук іде виключно у моніторинг (навушники) і відсікається від зовнішніх програм (ін'єкція / кабель).
   - Іконка кнопки: `🎙️` (розм'ючено) $\leftrightarrow$ `🎙️❌` (замучено для інших).
   - Стан зберігається в `musicpad_state.json` під ключем `mute_track_to_others`.

5. **Вимкнення спливаючої хмарки «Зараз грає»**:
   - Хмарка `SpeechBubble` більше не показується при старті чи перемиканні треків.

## Consequences

- Інтерфейс отримує естетичний, центрований та інформативний вигляд із назвою, виконавцем та обкладинкою в єдиному блоці.
- Виправлено порядок кнопок у панелі інформації про категорію.
- Збережено 100% сумісність з існуючими гарячими клавішами, темами та тестами.
