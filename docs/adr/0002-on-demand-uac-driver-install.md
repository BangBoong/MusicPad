# Драйвер MusicPad ставить UAC-helper на вимогу; exe лишається портативним; приймаємо DisableProtectedAudioDG=1

MusicPad лишається портативним `MusicPad.exe` без прав адміністратора й без інсталятора. Драйвер MusicPad встановлюється, видаляється й ремонтується лише за кнопкою в налаштуваннях: той самий exe перезапускається з `--driver install|uninstall|repair` через UAC. Helper копіює DLL у `%ProgramFiles%\MusicPad\` (не в тимчасову папку PyInstaller), бекапить змінені налаштування endpoint'а в `%ProgramData%\MusicPad\` і відновлює їх під час видалення.

Непідписану APO Windows завантажує в `audiodg.exe` лише з `DisableProtectedAudioDG=1` (HKLM). Це послаблює захист для всієї системи, тому діалог встановлення прямо попереджає про це, а під час видалення відновлюється попереднє значення, а не примусовий `0`: на нього можуть покладатися інші програми, наприклад Equalizer APO.

## Considered Options

- **Повноцінний інсталятор (Inno Setup) для всієї програми** — відкинуто: ламає модель «завантажив exe і запустив», хоча драйвер потрібен не всім.
- **Підпис через Microsoft attestation (EV-сертифікат, Partner Center, driver extension INF)** — відкладено: гроші, бюрократія та інший шлях встановлення. Лишається можливістю на майбутнє, яка дозволить прибрати `DisableProtectedAudioDG`.
