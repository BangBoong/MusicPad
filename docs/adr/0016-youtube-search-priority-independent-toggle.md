# ADR 0016: YouTube Search Priority Independent Toggle

## Context
Пошук YouTube у додатку раніше базувався переважно на модулі `ytmusicapi` (каталог YouTube Music).
YouTube Music фокусується на студійних музичних композиціях та офіційних альбомах. У результаті запити користувачів на пошук специфічних відеоматеріалів (меми, звукові ефекти для саундпада, кавери, подкасти, геймплейні репліки чи точні назви роликів з YouTube) або підмінялися випадковими треками з музичного каталогу зі схожими словами, або взагалі не повертали релевантних результатів.

При цьому користувач мав можливість обирати режими фільтрації альбомів («Всі результати», «Без альбомів», «Тільки альбоми»). Додавання пріоритету YouTube не повинно скидати або змушувати користувача заново налаштовувати свій вибір щодо альбомів при поверненні до звичайного музичного пошуку.

## Decision
1. **Незалежна опція-перемикач «Пріоритет YouTube (пошук за назвою)»**:
   - Реалізовано окрему змінну `yt_priority_var` (`BooleanVar(value=False)`), ортогональну до `yt_filter_var` (`"all"`, `"no_albums"`, `"albums_only"`).
   - У випадаючій панелі «Фільтр» додано незалежний інтерактивний чекбокс `☑ Пріоритет YouTube (пошук за назвою)`.
   - У контекстне меню кнопки фільтра додано чекбокс для швидкого перемикання пріоритету в 1 клік.
2. **Візуальне розмежування та стан неактивності**:
   - При увімкненому пріоритеті YouTube вибір радіокнопок альбомів зберігається недоторканим, але візуально стає приглушеним (`muted_fg`), сигналізуючи, що зараз діє прямий пошук відео за назвою.
   - Підпис кнопки фільтра динамічно адаптується: `Фільтр: YouTube (за назвою) ▾`.
3. **Прямий бекенд пошуку `ytsearch`**:
   - `AudioEngine.search_youtube` отримав параметр `youtube_priority: bool = False`.
   - При `youtube_priority=True` запит надсилається безпосередньо до `YoutubeDL` (`ytsearch{limit}:{query}`), повертаючи відеоролики з глобального каталогу YouTube (`www.youtube.com`) за найвищою релевантністю назві, без нав'язування музичних фільтрів YTMusic.
4. **Збереження стану**:
   - Параметр `yt_search_priority` зберігається у `state.json` разом із `yt_search_filter` та `yt_search_limit`.

## Consequences
- Користувачі можуть знаходити будь-які відеоролики, меми та звуки з YouTube за точним збігом назви.
- Стан вибору альбомів залишається незмінним при увімкненні та вимкненні пріоритету YouTube.
- Повністю підтримується вибір ліміту треків (5–35) та локалізація (UK / EN).
