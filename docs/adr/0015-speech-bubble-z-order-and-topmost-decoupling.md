# ADR 0015: SpeechBubble Z-Order Coupling and System Topmost Decoupling

## Context
Користувацький віджет спливаючих повідомлень `SpeechBubble` (`tk.Toplevel`) раніше мав жорстко встановлений прапорець `self.attributes("-topmost", True)` поряд із `overrideredirect(True)`.

В операційній системі Windows виклик `-topmost True` надає вікну розширений стиль `WS_EX_TOPMOST` (`HWND_TOPMOST`), що підіймає вікно над усіма іншими сторонніми додатками операційної системи (браузерами, іграми, редакторами тощо), навіть коли фокус знаходиться поза вікном MusicPad, або коли вікно додатку частково чи повністю перекрито іншим додатком.

## Decision
1. **Зняти безумовний `-topmost True`**:
   - `SpeechBubble` прив'язується до батьківського вікна за допомогою `self.transient(master)`.
   - Завдяки `transient(master)` на рівні Win32 API хмарка стає дочірнім/належним (`owned`) вікном вікна MusicPad. При активації сторонніх програм ОС віконна група MusicPad разом із хмаркою коректно розташовується під активним додатком.
2. **Синхронізація з опцією «Поверх усіх вікон» (`always_on_top`)**:
   - Створено метод `SpeechBubble._sync_topmost()`, який перевіряє атрибут `-topmost` батьківського вікна (`master`).
   - Хмарка отримує статус `topmost` лише у випадку, якщо сам MusicPad має увімкнену опцію `always_on_top`.
   - Синхронізація автоматично викликається при кожному `show()` сповіщення, а також при зміні налаштування `always_on_top` у `_apply_settings`.
3. **Автоматичне приховування при згортанні та втраті фокусу**:
   - `SpeechBubble` підписується на події `<Unmap>` та `<FocusOut>` батьківського вікна.
   - При згортанні вікна (`<Unmap>`) хмарка миттєво ховається (`hide_immediate()`).
   - При виході фокусу за межі застосунку (`<FocusOut>`, коли `focus_get() is None`) хмарка ховається з невеликою затримкою 150мс, запобігаючи помилковому приховуванню при переході між внутрішніми вікнами (наприклад, вікном налаштувань чи діалогами).
   - При знищенні (`destroy`) віджет акуратно відписується від подій `master`.

## Consequences
- Сповіщення більше не зависають поверх сторонніх програм користувача.
- Повністю збережено плавність появи, теми та підтримку кількох моніторів.
- Усі 91 юніт-тест проходять успішно.
