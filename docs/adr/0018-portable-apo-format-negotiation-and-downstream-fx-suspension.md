# Універсальна сумісність Драйвера MusicPad на різних ПК: узгодження форматів `S_FALSE`, призупинення MFX/SFX та валідація цільового мікрофона

У тракті захоплення Windows (`audiodg.exe`) сигнал іде у зворотному до рендеру порядку: **`Цільовий мікрофон -> EFX -> MFX -> SFX -> Застосунок`**. На мікрофонах зі сторонніми звуковими пакетами (Realtek HD Audio, Intel SST, Waves MaxxAudio, Nahimic) вендорські MFX/SFX-обробники (нейромережеві шумодави та фільтри голосу) стоять **після** нашої EFX і глушать ін'єктовану музику як нецільовий шум. Крім того, для моно-мікрофонів (1 канал) або форматів `PCM int16` служба `audiodg.exe` під час `IsInputFormatSupported` / `IsOutputFormatSupported` очікує повернення `S_FALSE` із підстановкою підтримуваного `IEEE_FLOAT` формату (`*ppSupportedFormat = pOppositeFormat`), а не помилки `APOERR_FORMAT_NOT_SUPPORTED`.

Тому під час встановлення Драйвера MusicPad ми:
1. У `FxProperties` цільового мікрофона реєструємо EFX для всіх чотирьох режимів захоплення (`DEFAULT`, `COMMUNICATIONS`, `SPEECH`, `RAW`) і тимчасово вилучаємо вендорські ключі `SFX`/`MFX`/`LFX` (із повним збереженням у `backup.json` та відновленням при видаленні або перенесенні драйвера на інший мікрофон).
2. У `MusicPadAPO::CheckFormat` повертаємо `S_FALSE` із валідним `IEEE_FLOAT` форматом (`pOppositeFormat` або 48 кГц стерео float32), дозволяючи `audiodg.exe` автоматично вставляти системний конвертер форматів перед та після нашої APO.
3. Забороняємо встановлення та перевірку драйвера на неіснуючих або неактивних (`DeviceState != 1`) GUID мікрофонів (зокрема перенесених у `musicpad_config.json` з іншого ПК), а C++-рантайм лінкуємо виключно статично (`/MT` у CMake та `-static` у MinGW).
