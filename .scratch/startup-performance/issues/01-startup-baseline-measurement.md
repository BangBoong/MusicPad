# 01: Базова лінія часу запуску та скрипт вимірювання

**What to build:** Dev-скрипт вимірювання запуску, який запускає задану команду (зібраний `MusicPad.exe` або `python main.py`), чекає появи видимого верхньорівневого вікна з заголовком «MusicPad» (Win32 `FindWindowW` / `IsWindowVisible` через `ctypes`), фіксує час від старту процесу, завершує процес і повторює N разів, виводячи медіану/мін/макс. Вимірювання ззовні обов'язкове, бо в onefile-режимі розпакування виконує окремий процес-завантажувач. За допомогою скрипта зафіксувати базову лінію для поточної onefile-збірки та `python main.py`, а також топ найдорожчих імпортів за `python -X importtime`. Див. [spec](../spec.md).

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] Скрипт приймає команду та кількість запусків N, підтримує теплий запуск (перший запуск відкидається як прогрівальний) і виводить медіану/мін/макс у мс.
- [x] Скрипт коректно завершує запущений процес (включно з дочірнім процесом onefile-завантажувача) після кожного вимірювання та має таймаут, якщо вікно не з'явилося.
- [x] Записано базову лінію: onefile `dist/MusicPad.exe` (теплий запуск, N ≥ 5) і `python main.py` (N ≥ 5).
- [x] Записано топ-15 найдорожчих імпортів за `python -X importtime` (кумулятивний час).
- [x] Результати додано до цього файлу під `## Comments`; ціль «≤ ~2 с» підтверджено або уточнено з урахуванням базової лінії.
- [x] Скрипт не підключено до CI.

#### Висновки та підтвердження цілі «≤ ~2 с»:
- **~5.7 секунд (81% часу старту бінарника)** витрачається виключно на onefile-розпакування та розтискання UPX у тимчасову директорію `%TEMP%/_MEIxxxxxx`.
- Сам Python-код стартує за **1.29 с**, з яких понад **700 мс** — це імпорти (зокрема `yt_dlp`, `sounddevice`, `numpy`, `ytmusicapi`).
- Перехід на **onedir без UPX** (задача 03) одразу скоротить час запуску з ~7.0 с до рівня ~1.3 с.
- Подальший фоновий прогрів модулів пошуку та відкладена ініціалізація аудіо (задачі 05-07) дозволять вікну з'являтися ще швидше (орієнтовно за ~0.5-0.8 с).
- Ціль **«≤ ~2 с при теплому запуску»** повністю реалістична і навіть перевиконувана із запасом.
