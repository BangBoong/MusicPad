# 03: Onedir ZIP-реліз без UPX

**What to build:** Релізний пайплайн збирає PyInstaller **onedir** (тека `MusicPad/` з `MusicPad.exe` та `_internal/`) без UPX і публікує в GitHub Releases лише портативний ZIP із цією текою. Користувач розпаковує ZIP і запускає `MusicPad.exe`; нічого не розпаковується під час запуску. Самотест виконується для onedir-бінарника і звітує, що збірка onedir. Обидва README і глосарій описують новий формат. Див. [spec](../spec.md), [ADR-0020](../../../docs/adr/0020-stay-on-python-native-hot-path.md) (частково замінює ADR-0009 у форматі артефакту).

**Blocked by:** 01: Базова лінія часу запуску та скрипт вимірювання; 02: Префакторинг — єдине правило кореня застосунку з підтримкою `dist/<тека>/`

**Status:** resolved

- [x] Специфікація PyInstaller збирає onedir (`EXE` з `exclude_binaries=True` + `COLLECT` з іменем `MusicPad`), `upx=False`; перелік вбудованих ресурсів не змінено.
- [x] Усі пошуки ресурсів (FFmpeg/FFprobe, нативні DLL драйвера MusicPad і DSP-ядра, модель DeepFilterNet, assets, дані `ytmusicapi`) працюють з `_internal/`.
- [x] Релізний пайплайн: самотест для onedir `MusicPad.exe`; ZIP `MusicPad-windows-x64.zip` містить теку `MusicPad/` (+ README, іконку); onefile `MusicPad.exe` не завантажується ні в Actions artifacts, ні в GitHub Release.
- [x] Самотест звітує `onedir` (наявність `_internal/` у frozen-режимі); у frozen-режимі `ok` вимагає `onedir == true`.
- [x] Тест зібраного бінарника оновлено на onedir-шлях; очікувані шляхи `.cache` — корінь репозиторію (завдяки задачі 02).
- [x] Текстові перевірки специфікації PyInstaller і релізного workflow: `upx=False`, наявність `COLLECT`, архівація теки, відсутність onefile-артефакту.
- [x] Обидва README (EN/UA): «завантажте ZIP → розпакуйте → запустіть `MusicPad.exe`», «оновлення — розпакуйте поверх старої теки», «розпаковуйте в теку з правом запису (не `Program Files`)».

### Порівняння з базовою лінією:
- **Onefile `dist/MusicPad.exe` (з UPX):** 6997.0 ms (7.00 с)
- **Onedir `dist/MusicPad/MusicPad.exe` (без UPX):** 1143.2 ms (1.14 с)

- Ціль «≤ ~2 с» уже досягнута з великим запасом навіть до впровадження лінивих імпортів та відкладеної ініціалізації аудіо.
