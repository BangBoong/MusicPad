# 06: Завантаження шумозаглушення DeepFilterNet лише за вимогою

**What to build:** Модель і бібліотека шумозаглушення DeepFilterNet більше не завантажуються, коли шумозаглушення вимкнене. Якщо воно увімкнене (збережений стан) — модель завантажується у фоні, не блокуючи запуск; при ввімкненні в налаштуваннях — теж у фоні без зависання інтерфейсу. Поки модель вантажиться, голос проходить через решту обробки голосу без цієї стадії, а потім шумозаглушення підключається автоматично. Вимкнення шумозаглушення не потребує перезапуску. Див. [spec](../spec.md).

**Blocked by:** 01: Базова лінія часу запуску та скрипт вимірювання

**Status:** resolved

- [x] При вимкненому шумозаглушенні модель/бібліотека DeepFilterNet не завантажується ні при запуску, ні під час відтворення.
- [x] При увімкненому (збереженому) шумозаглушенні модель завантажується у фоні; до готовності голос проходить без цієї стадії, після — стадія підключається автоматично з поточним балансом wet/dry.
- [x] Ввімкнення в налаштуваннях запускає фонове завантаження без блокування UI; повторні перемикання під час завантаження не запускають паралельних завантажень.
- [x] Помилка завантаження моделі показується користувачеві й не ламає решту обробки голосу та ін'єкцію.
- [x] Тести: вимкнено → не завантажено; ввімкнення → завантажено у фоні (детермінована підміна завантаження); помилка завантаження; наявні тести обробки голосу проходять.
