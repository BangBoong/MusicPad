# 01: Повноширинний пошуковий рядок YouTube з іконкою лупи, кнопкою очищення `✕` та запуском за `Enter`

**What to build:** Пошуковий рядок у розділі «YouTube / YouTube Music» розширюється на всю доступну ширину панелі без окремої кнопки «🔍 Знайти» праворуч. Усередині пошукового рядка ліворуч відображається векторна іконка лупи, а праворуч — інтерактивна кнопка швидкого очищення `✕` (показується лише тоді, коли в полі є текст; при кліку очищує текст і залишає фокус у полі вводу, не скидаючи таблицю результатів пошуку). Пошук запускається натисканням клавіші `Enter`, усі підказки інтерфейсу локалізовані українською та англійською мовами, а кольори поля й іконок адаптуються під темну (`Dark`) і світлу (`Light`) теми оформлення.

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] Вилучено кнопку «🔍 Знайти» / «🔍 Search» праворуч від пошукового рядка YouTube; пошуковий рядок займає всю доступну ширину верхньої панелі.
- [x] Ліворуч усередині контейнера пошукового рядка відображається векторна іконка лупи, стилізована під активну тему (`Dark` / `Light`).
- [x] Праворуч усередині контейнера пошукового рядка відображається кнопка очищення `✕` за наявності тексту в полі вводу та ховається, коли поле порожнє.
- [x] Клік на кнопку `✕` миттєво очищує текст пошукового рядка і повертає фокус у поле вводу, зберігаючи вже відображені результати пошуку.
- [x] Натискання `Enter` у пошуковому рядку запускає пошук треків/альбомів або пряме відтворення за посиланням.
- [x] Статусні підказки пошукового рядка локалізовані українською («Введіть запит і натисніть Enter») та англійською («Enter query and press Enter») мовами, а існуючі тести оновлені й проходять успішно.
