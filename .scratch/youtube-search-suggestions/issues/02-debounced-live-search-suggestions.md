# 02: Асинхронні пошукові підказки (`get_search_suggestions`) з дебаунсом 300 мс та змішаним форматуванням тексту в оверлеї

**What to build:** Під час введення літер або слів у пошуковий рядок YouTube після дебаунсу `300 мс` програма асинхронно у фоновому робочому потоці запитує **пошукові підказки** через `get_search_suggestions()` (без блокування інтерфейсу та з ігноруванням застарілих відповідей) і відображає їх у спливаючому оверлеї безпосередньо під пошуковим рядком (до 7 рядків з іконкою лупи ліворуч). У кожному рядку вже введена частина тексту відображається **напівжирним** шрифтом (`bold`), а запропоноване продовження — звичайним (`normal`) в одну лінію. Підтримується вибір мишею, навігація клавішами `↑` / `↓` (із підстановкою тексту в поле вводу без перезапуску дебаунсу), повернення початково набраного тексту при `Escape` або виході вище першого елемента, пропуск підказок при введенні прямого URL та підтримка обох тем (`Dark` / `Light`) і локалей (`UK` / `EN`).

**Blocked by:** 01: Повноширинний пошуковий рядок YouTube з іконкою лупи, кнопкою очищення `✕` та запуском за `Enter`

**Status:** resolved

- [x] Реалізовано отримання пошукових підказок через `get_search_suggestions()` із безпечною обробкою порожніх запитів та мережевих помилок.
- [x] Введення тексту запускає дебаунс `300 мс`, після чого мережевий запит виконується у фоновому робочому потоці з перевіркою токена генерації та потокобезпечним оновленням UI.
- [x] Спливаючий список пошукових підказок відображається як поверхневий оверлей під пошуковим рядком (до 7 рядків з іконкою лупи) і ховається при порожньому полі, натисканні `✕`, `Escape`, кліку поза списком або введенні прямого URL.
- [x] У кожному рядку підказки частина тексту, що збігається з введеним запитом користувача, рендериться напівжирним (`bold`), а решта підказки — звичайним (`normal`) шрифтом в один рядок.
- [x] Клік мишею на підказку або натискання `Enter` закриває список і негайно запускає пошук.
- [x] Навігація клавішами `↑` / `↓` підсвічує рядки та підставляє їхній текст у пошуковий рядок без перезапуску таймера дебаунсу, а перехід вище першого рядка або `Escape` повертає початково набраний текст.
- [x] Оверлей підказок, текст та іконки коректно відображаються у темній (`Dark`) та світлій (`Light`) темах.
